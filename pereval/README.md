# Перевал

Игра про спортивный туризм в браузере. Без фреймворков и внешних ассетов: TypeScript, HTML5 Canvas, Vite.

**Цель:** провести группу из четырёх туристов по категорийному маршруту — отметиться на всех КП, переправиться через реки, взять перевалы и вернуться в посёлок до контрольного срока. За маршрут начисляются очки и спортивный разряд, рекорды сохраняются.

## Что внутри

- Три категории сложности (I–III к. с.): карта больше, КП больше, гор и рек больше, срок жёстче, коэффициент очков выше.
- Процедурная карта: луга, лес, болота, курумник, ледники, скальный хребет посередине с перевалами, реки с мостиками, озёра, вершины, стартовый и финишный посёлки. Все КП гарантированно достижимы.
- Ходовой день на 10 часов. Стоимость клетки зависит от местности, погоды, веса рюкзаков, усталости, травм и морали.
- Сборы перед выходом: шесть кандидатов с разной техникой, силой и ролями — выбираете четверых; раскладка еды, газа, аптечки и верёвки с живым подсчётом веса и его влияния на скорость.
- Группа: у каждого участника имя, роль (руководитель, завхоз, медик, реммастер), техника, сила, здоровье, выносливость и травмы. Роли дают бонусы.
- Дилеммы в пути (не чаще раза в день): заблудившийся турист, ягодная поляна, медвежьи следы, короткий путь по кулуару, гроза, изба, записка в туре, порванная лямка… Каждая — выбор между временем, силами, едой и моралью; часть вариантов появляется только при нужной роли или аптечке.
- Снаряжение: еда в человеко-днях, газ для горелки, верёвка, аптечка. Вес группы замедляет ход.
- Погода с прогнозом на завтра: ясно, облачно, дождь, гроза, снег. Гроза и снег закрывают перевалы и ледники, дождь поднимает воду в реках.
- Технические этапы с мини-играми:
  - **Переправа** — вброд или навесная по верёвке. Каждый участник по очереди останавливает бегунок в зоне, ширина зоны зависит от техники, усталости и погоды.
  - **Перевал** — руководитель провешивает перила: нужно повторить последовательность стрелок за отведённое время.
  - Промах стоит сил, падение — здоровья и еды (промок рюкзак), возможна травма.
- Ночёвка и днёвка, случайные события в лагере (черничник, рыбалка, медвежьи следы, засорившаяся горелка, встреча с другой группой…), трещины на леднике, живые камни, потерянная тропа.
- Очки: КП, финиш, вершины, запас по сроку, здоровье и мораль минус падения и днёвки, умноженные на коэффициент категории. Разряды от значка «Турист России» до мастера спорта.
- Автосохранение после каждого действия в localStorage, кнопка «Продолжить поход», таблица 10 лучших результатов.
- Управление с клавиатуры, мышью (клик по карте — путь с предварительным подсчётом часов) и экранными кнопками на телефоне.
- Звук синтезируется на Web Audio, клавиша `M` выключает.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты движка (vitest)
npm run build      # сборка в dist/
npm run sim -- 50  # бот проходит 50 маршрутов каждой категории и печатает статистику
npm run map -- 7 2 # ASCII-карта для seed 7, категория 2
```

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки, WASD | Шаг на соседнюю клетку |
| Клик по карте | Идти к клетке по кратчайшему пути |
| `C` | Ночёвка |
| `R` | Днёвка (только с утра) |
| Пробел / Enter | Остановить бегунок на переправе |
| Стрелки | Повторить последовательность на перевале |
| `M` | Звук вкл/выкл |
| `?` | Помощь, `Esc` — меню |

## Структура

```
src/game/   движок без DOM: генерация карты, поиск пути, поход, этапы, очки, сохранения
src/ui/     отрисовка на Canvas (renderer.ts) и синтез звука (sound.ts)
src/main.ts ввод, панели, мини-игры, меню
tests/      vitest-тесты движка
scripts/    sim.ts — бот для проверки баланса, ascii.ts — печать карты
```

Движок не зависит от браузера: тесты и симулятор используют те же модули, что и игра. Мини-игры в интерфейсе превращают действия игрока в «качество» от 0 до 1 для каждого участника, а движок по нему решает, кто перешёл чисто, кто оступился, а кто упал.

Для автоматических прогонов страница с параметром `?debug` выставляет `window.__pv` с доступом к состоянию игры.
