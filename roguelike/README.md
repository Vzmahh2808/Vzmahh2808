# Сердце подземелья

Пошаговый рогалик в браузере. Без фреймворков и внешних ассетов: TypeScript, HTML5 Canvas, Vite.

**Цель:** спуститься на 10-й этаж, победить Владыку подземелья и забрать Сердце подземелья. Смерть окончательна, но рекорды сохраняются.

## Что внутри

- Процедурная генерация этажей: комнаты, коридоры, двери, лестница вниз. Каждый этаж гарантированно связный.
- Поле зрения по алгоритму recursive shadowcasting, «туман войны» с памятью исследованных клеток.
- 12 видов монстров с разным поведением: преследование, хаотичное движение, бегство при низком здоровье, яд, вытягивание здоровья, регенерация, босс.
- Предметы: зелья, свитки (телепорт, картография, огненный шар), оружие и броня со слотами экипировки, золото.
- Опыт и уровни, естественная регенерация, отравление.
- Автоисследование этажа и путешествие по клику мыши с остановкой при появлении врага.
- Автосохранение после каждого хода в localStorage, кнопка «Продолжить» и таблица 10 лучших результатов.
- Управление с клавиатуры (стрелки, WASD, vi-клавиши, цифровая клавиатура), мышью и экранными кнопками на телефоне.
- Анимации на Canvas: плавное скольжение, выпады при атаке, вспышки урона, тряска экрана, кольца заклинаний, затемнение при спуске, виньетки смерти и победы. Учитывается `prefers-reduced-motion`.
- Звук синтезируется на Web Audio прямо в браузере: удары, промахи, золото, зелья, свитки, огненный шар, уровень, спуск, смерть, победа. Клавиша `M` или кнопка в шапке выключает звук.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты движка (vitest)
npm run build      # сборка в dist/
npm run sim -- 100 # бот играет 100 партий и печатает статистику баланса
```

## Управление

| Клавиши | Действие |
|---|---|
| Стрелки, WASD, HJKLYUBN, 1–9 | Движение в 8 направлениях |
| `.` или `5` | Пропустить ход |
| `G` | Подобрать предмет |
| `I` | Рюкзак (внутри: буква или Enter — использовать, D — бросить) |
| `>` | Спуститься по лестнице |
| `O` | Автоисследование |
| Клик по карте | Идти к клетке |
| `M` | Звук вкл/выкл |
| `?` | Помощь, `Esc` — меню |

## Структура

```
src/game/   движок без DOM: генерация, FOV, поиск пути, бой, ИИ, сохранения
src/ui/     отрисовка на Canvas (renderer.ts) и синтез звука (sound.ts)
src/main.ts ввод, панели, меню
tests/      vitest-тесты движка
scripts/    sim.ts — бот для проверки баланса
```

Движок не зависит от браузера, поэтому его можно гонять в Node: тесты и симулятор используют те же модули, что и игра. Движок отдаёт наружу типизированные события (`GameEvent`), а рендерер и звук реагируют на них независимо.

Для автоматических прогонов страница с параметром `?debug` выставляет `window.__dd` с доступом к состоянию игры.
