# Прилив

Открытый низкополигональный 3D-город в браузере в духе классических «песочниц» про машины. Своя вселенная, своя графика: всё генерируется кодом, внешних моделей и текстур нет.

## Слой 1: город и машины

- Процедурный город: сетка кварталов, небоскрёбы в центре и малоэтажка по краям, парки, тротуары, разметка, зебры, фонари, деревья.
- Персонаж от третьего лица с анимацией ходьбы и бега.
- Машины с аркадной физикой: разгон, торможение, задний ход, занос на ручнике, столкновения со зданиями и друг с другом, урон.
- Четыре типа машин: седан, спорткар, фургон, пикап.
- Угон: можно сесть в любую машину, в том числе в едущую по улице.
- Трафик с ИИ: едет по своей полосе, выбирает повороты на перекрёстках, тормозит перед препятствиями.
- Камера с двумя режимами, расширение поля зрения на скорости, тени от солнца.
- Мини-карта, спидометр, полоска здоровья.
- Звук двигателя по оборотам, сигнал, удары при авариях. Всё синтезируется на Web Audio.

## Слой 2: жизнь на улицах и разрушения

- 80 прохожих ходят по сети тротуаров вокруг кварталов и переходят дороги по зебрам. Толпа всегда держится рядом с игроком.
- Прохожие разбегаются от быстрой машины, от сигнала, от огня и взрывов. Трафик тормозит перед людьми на переходе.
- Наезд сбивает пешехода: он отлетает, падает и через несколько секунд исчезает. Остальные рядом в панике.
- При угоне водитель выпрыгивает и убегает. Из горящей машины водитель тоже выбирается сам.
- Повреждения машин: краска темнеет, кузов проседает. Сначала белый дым, потом чёрный, потом пожар.
- Горящая машина взрывается через несколько секунд: огненный шар, искры, вспышка, тряска камеры, столб дыма.
- Взрыв бьёт по соседним машинам и может поджечь их, получается цепная реакция. Сгоревшие остовы через время заменяются новым трафиком.
- Следы шин и дым от покрышек при заносе, визг резины, звуки удара и взрыва.
- Машины и люди поднимаются на тротуар, а не проваливаются в него.
- Гибель и возрождение: от взрыва, от огня в горящей машине или под колёсами.

## Управление

| Клавиши | Действие |
|---|---|
| WASD или стрелки | Идти или рулить |
| Shift | Бежать |
| E | Сесть в машину или выйти |
| Пробел | Ручной тормоз |
| H | Сигнал |
| C | Сменить камеру |
| M | Звук |

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # тесты города, физики, повреждений, трафика и прохожих
npm run build
```

## Структура

```
src/core/      генератор случайных чисел, ввод
src/world/     генерация города (чистая логика) и его 3D-меши
src/entities/  физика и повреждения машин, модели, ИИ трафика и прохожих
src/fx/        частицы дыма и огня, следы шин
src/ui/        мини-карта
src/audio/     синтез звука двигателя
tests/         vitest
```

Логика города, физики и трафика не зависит от Three.js, поэтому тестируется в Node.
