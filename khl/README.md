# Шайбу!

Аркадный хоккей в браузере: вид сверху, горизонтальный каток 60×26 м, пять на пять, овертайм три на три и буллиты. Играть можно против компьютера, вдвоём на одной клавиатуре и на телефоне. Всё рисуется и звучит из кода, внешних картинок и звуков нет.

Лига и клубы вымышлены («Евразийская лига», 22 клуба в реальных городах, свои названия и цвета). Реальные названия и символика КХЛ не используются, причины в [RESEARCH.md](RESEARCH.md).

## Слой 1: матч

- **Матч.** Три периода, на табло идут привычные 20:00, а в жизни период длится 1:30, 2:30 или 4:00. Гол, вбрасывание, перерыв, овертайм 3 на 3 (в плей-офф пять на пять), серия буллитов до победителя.
- **Катание.** Скольжение с инерцией и заносом, поворот с ограничением скорости, рывок за счёт сил, столкновения с бортами, воротами и друг с другом.
- **Шайба.** Отскоки от бортов, штанг и сетки, проверка столкновений подшагами, чтобы быстрый бросок не пролетал сквозь стены.
- **Бросок.** Тап даёт кистевой, удержание до 0,85 с даёт щелчок. Если смотреть на ворота, бросок сам уходит в дальний от вратаря угол. Нажатие в момент паса даёт бросок с первого касания.
- **Пас.** Ищет партнёра в направлении джойстика с упреждением. Без шайбы та же кнопка меняет игрока.
- **Отбор.** Клюшкой у шайбы (с шансом), на скорости силовым приёмом: соперник падает и теряет шайбу.
- **Вратарь.** Встаёт между шайбой и центром ворот, выходит на угол, читает бросок с задержкой реакции, падает в шпагат, ловит и отбивает с отскоком, иногда накрывает шайбу.
- **Компьютер.** Расстановка по ролям, давление на шайбу, поддержка владельца, выбор между броском и пасом, схема обороны. Сложность меняет скорость, точность и частоту решений.
- **Интерфейс.** Табло, мини-карта, баннеры гола с автором и помощниками, статистика матча, сенсорные кнопки, пауза.
- **Звук.** Толпа из шума, которая растёт у ворот, сирена гола, хлопки-кричалка, орган, удары клюшек, борта и штанги.

## Управление

| | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение | WASD (или стрелки, если играет один) | Стрелки |
| Бросок | F или J (держать для щелчка) | . |
| Пас, смена игрока | Пробел или E | Enter |
| Отбор | G или K | / |
| Рывок | Левый Shift | Правый Shift |

Пауза: Esc. Звук: M. На телефоне: джойстик слева, кнопки справа.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
npm test        # физика, матч, овертайм, буллиты, управление
npm run build
N=40 npx vite-node scripts/balance.ts   # статистика матчей ИИ против ИИ
```

Для проверки на компьютере: `?touch` включает сенсорное управление, `?auto=0,1` сразу начинает матч клубов 0 и 1, `?debug` открывает `window.__khl`.

## Структура

```
src/core/     генератор случайных чисел, векторы
src/sim/      чистая логика без DOM: каток, состояние, физика, действия, вратарь, ИИ, ход матча
src/game/     клубы, составы, настройки
src/render/   кэш катка, камера, спрайты и эффекты
src/input/    клавиатура на двоих, сенсорное управление
src/audio/    синтез звука
src/ui/       табло, экраны меню
tests/        vitest
scripts/      баланс
research/     исследования
```

Симуляция не зависит от браузера, поэтому целые матчи проверяются в Node. Один и тот же сид даёт один и тот же матч.
